## Deterministic fixture correction during execution

The first deterministic probe-failure fixture exposed a test-ingress defect rather than a production lifecycle defect.

A local `file:` npm fixture was bind-mounted read-only, so npm attempted to chmod the fixture package during installation and failed with `EROFS`. Making the bind writable alone then failed with `EPERM` because the host copy was root-owned while the container service user was `21001:21001`.

The verifier was corrected to:

- copy the tracked fixture package into the test's unique disposable temp root;
- assign that disposable copy to the configured fixture UID/GID;
- mount only that disposable copy writable for local npm installation.

The tracked source fixture is not mutated, and production runtime behavior is unchanged. The corrected exact commit then passed the complete verifier.
