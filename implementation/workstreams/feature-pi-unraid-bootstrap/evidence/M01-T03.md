## Corrective implementation detail found during execution

The first T03 fixture attempt failed during the synthetic Git commit even though the setup script had reported success.

Independent runtime probing showed this was a test race, not a persistent-Git-config defect:

- Docker had reported the container running while its root entrypoint was still reconciling the `pi` account;
- an immediate `docker exec -u pi` resolved the image-time UID/GID `1000:1000` and created `~/.gitconfig` under that identity;
- after entrypoint reconciliation, the same named user resolved as `21001:21001`, so the early file was unreadable;
- the test was corrected to wait until the `pi` account matches configured UID/GID and the service user can write `/home/pi` before any operator action.

No production entrypoint or T02 source changed. The corrected exact source head then passed the full T03 fixture verification.

## Post-review corrective implementation and retest

The first independent M01-T03 review recorded RED finding F1 in `implementation/workstreams/feature-pi-unraid-bootstrap/evidence/M01-T03-review.md`: the managed GitHub SSH block was appended after preserved user SSH config, but OpenSSH uses the first obtained value for each directive. A pre-existing matching stanza could therefore defeat the intended strict settings.

Bounded corrective changes:

- `scripts/configure-operator.sh` now writes its bounded managed `Host github.com` block before preserved user SSH configuration, so its GitHub-specific `StrictHostKeyChecking yes` and persistent `UserKnownHostsFile` values win while unrelated user configuration remains present.
- `scripts/verify-git-worktree-foundation.sh` seeds a conflicting earlier-style GitHub stanza with `StrictHostKeyChecking no` and an unsafe alternate known-hosts path, plus an unrelated host stanza; after setup it verifies effective `ssh -G github.com` remains strict and the unrelated host setting is preserved.
- The operator documentation and fixture invoke the tracked setup script through `sh`, avoiding an unstated dependency on Git executable-mode metadata for this repository script.
