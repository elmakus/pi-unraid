- Refresh checkout/UID/GID/path/workstation/dependency state immediately before mutation.

3. Production Compose/security/mount/restart/logging contract is intact and service becomes healthy.

5. Pi provider/client configuration and native session state survive restart/recreation.
6. Project/worktree operations and authorized Git SSH/`gh` checks succeed under the non-root service identity.
7. Strict GitHub host verification, required tool inventory and prohibited-mount/service checks are GREEN.
8. Pi appdata is inside the normal backup surface and not explicitly skipped.
9. Codex-LB data remains unmounted/unmodified by Pi and workstation remains independent/unchanged.
10. Evidence is sanitized of client keys, OAuth tokens and private transcript content.
