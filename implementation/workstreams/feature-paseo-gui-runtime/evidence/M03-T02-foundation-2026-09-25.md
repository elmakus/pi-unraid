## Implemented foundation

- `scripts/unraid_host_control_router.py` keeps GraphQL primary on every normal readback. SSH is used directly only for bounded explicit `api_gap`, `os_plugin_filesystem_recovery` or `forced_test` cases, or automatically for a real GraphQL transport/502/503/504 outage. Credential/auth/GraphQL application failures do not escalate to SSH.
- The router does not require or validate SSH credentials while GraphQL is healthy. SSH configuration is required only when fallback is actually selected, so the fallback plane cannot break the primary path merely because an SSH secret is absent.
- `scripts/unraid_ssh_fallback.py` enforces private non-symlink identity files, non-writable-by-group/other known_hosts, strict host-key checking, BatchMode, disabled password/keyboard-interactive authentication and IdentitiesOnly. Status output exposes only bounded metadata plus a truncated fingerprint.
- Fixed SSH probe/readback surfaces are machine-readable. A forced-test-only marker at `/tmp/pi-unraid-host-control-smoke` performs exact pre-state readback, mutation, post-state readback, automatic cleanup and restoration readback; it refuses to touch a pre-existing marker.
- `config/unraid-host-control/host-safety-policy.json` classifies the existing five one-container GraphQL mutations as ordinary and explicitly user-gates generic SSH administration plus host reboot, Docker-engine restart, Unraid OS upgrade, disk format, broad share/appdata deletion and broad network changes. Unknown operations fail closed.
- `scripts/unraid_host_safety_guard.py` requires exact scope-bound GREEN pre-mutation evidence for gated mutations, a private exact-scope `external_user_authorization` record, and a rollback anchor when the operation declares rollback applicable. No command in this repository manufactures the external authorization record.
- Generic gated SSH command output is not copied into structured output; only byte counts and truncated digests are returned. The child image gains the SSH client only; it does not add an SSH server, Docker socket or broad host mount.
- The implementation preserves the downstream P2 obligation: M06-T04 still owns real credential-backed GraphQL readback/mutation/restoration plus a forced bounded SSH fallback and return-to-GraphQL integration smoke before M07.
